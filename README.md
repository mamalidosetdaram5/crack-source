# 🌍 EarthCore Wars — راهنمای راه‌اندازی

## نصب

```bash
pip install -r requirements.txt
```

## متغیرهای محیطی

```env
BOT_TOKEN=توکن_بات_تلگرامت
MONGO_URI=mongodb://localhost:27017
```

یا مستقیم در فایل `earthcore_bot.py` تغییر بده.

---

## اجرا

```bash
python earthcore_bot.py
```

---

## ساختار بازی

### سولو
| دستور | کار |
|-------|-----|
| `/start` | ثبت‌نام + انتخاب کلاس |
| `/me` | پروفایل + منوی اصلی |
| `/mine` | حفاری سریع |

### گروه (توی گروه تلگرام)
| دستور | کار |
|-------|-----|
| `/newgroup` | ثبت گروه (فقط ادمین) |
| `/join` | عضویت |
| `/leave` | خروج |
| `/groupmenu` | مدیریت گروه |
| `/offer [gid] [res] [amt] [res] [amt]` | پیشنهاد تجاری |

---

## دکمه‌های رنگی

بازی از ایموجی‌های رنگی برای تمایز دکمه‌ها استفاده می‌کنه:

- 🟢 = عملیات مطمئن / ارزان
- 🔵 = متوسط
- 🟡 = نیاز به توجه
- 🔴 = خطر / گران / قوی
- 🔒 = قفل شده
